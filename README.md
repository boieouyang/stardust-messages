# Stardust Messages

Gold-leaf stardust that gathers into small encouraging messages.

**Controls**
- Any key: the dust forms a random message and stays
- Click: the dust bursts out and scatters back into a cloud
- Space: switch between night and day
- Move the mouse slowly to draw the dust along; swipe fast to fling it away

Built with [p5.js](https://p5js.org) for T564A Vibe Coding (Harvard Graduate School of Education), Week 3.

Remix of [Print Dust](https://openprocessing.org/@sammi/2988932) by Ivan Rudnicki (#WCCChallenge, "what's left behind").
